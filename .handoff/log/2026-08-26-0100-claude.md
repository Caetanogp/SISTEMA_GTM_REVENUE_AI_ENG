## Gotchas

  `develop` still runs the *old* rule until merged. Confirmed twice now; not a bug.
- **`claude plugin install`/`claude mcp add` can rewrite `.claude/settings.json` wholesale.**
  Always diff after running one -- it silently dropped the curl deny rule once already (fixed; the
  second plugin install this session did not repeat it, but keep checking).
- **This machine's git needs `http.sslBackend=schannel`** for any `https://` clone. Not a global
  config change -- apply per-command via `GIT_CONFIG_COUNT`/`GIT_CONFIG_KEY_0`/
  `GIT_CONFIG_VALUE_0` env vars, or ask the user before changing it globally.
- `claude plugin marketplace add owner/repo` tries SSH first and fails without keys configured --
  use the full `https://github.com/owner/repo` URL.

  matters, `ENABLE_STOP_REVIEW=0` keeps only the commit-time review.
