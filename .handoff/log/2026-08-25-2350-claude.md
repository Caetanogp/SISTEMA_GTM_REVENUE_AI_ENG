## Gotchas

- **The branch-policy hook can't unblock itself.** A commit that loosens
  `enforce_branch_policy.py`'s rule for `develop` still runs the *old* rule until it is actually
  merged into `develop` — the hook reads whatever's on disk at call time. That first loosening
  merge always needs the user; every merge after it is self-service. Don't be surprised if a
  similar governance change needs one manual assist again in the future.
- **Docker Desktop was not running** this session, so `docker compose up -d` was never executed
  end to end. The compose file parses (`docker compose config`), but pgvector has not been
  verified live — do that as part of step 2.
- `mypy`, `import-linter`, `uv`, `pre-commit` and `gitleaks` are not installed on this machine.
  `ruff`, `pytest`, `python 3.12`, `git` and `docker` (CLI) are.

  textual test that runs even without it installed.
