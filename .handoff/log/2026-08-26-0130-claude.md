## Gotchas

- **pre-commit is broken locally, see Done above.** Verify by hand (the exact commands are in
  AGENTS.md's Commands section); do not trust a clean `pre-commit run` to mean anything until this
  is actually fixed, and do not assume a hang means the code is wrong.
- **`scripts/hooks/enforce_branch_policy.py` has a false-positive bug**: it scans the *entire* raw
  Bash command text for a git-write pattern, so writing a doc file (via a Bash heredoc) that merely
  *mentions* "git merge" or "git commit" as prose can trigger a false BLOCKED, even on `develop`
  with nothing real being run. Workaround: write such files with the Write/Edit tool instead of a
  Bash heredoc (that tool isn't covered by this Bash-only hook, and is the better tool anyway).
  Worth a real fix later - the regex needs to distinguish an actual invoked command from arbitrary
  text inside a heredoc payload, which a portable Bash parser would do properly.
- The branch-policy hook can't unblock itself - a commit that loosens its own rule for `develop`
  still runs the *old* rule until merged. Not relevant again unless the policy changes further.
- `claude plugin install`/`claude mcp add` can rewrite `.claude/settings.json` wholesale - diff
  after running one.
- Docker Desktop still not confirmed running this session - `docker compose up -d` and the
  persistence layer (Next, step 3) need it.
- The domain layer must not import Pydantic - dataclasses only (import-linter + a textual test).
- Windows host: use Git Bash. Heredocs with apostrophes break in this shell - use the editor tool
  or a Python script for multi-line file writes.
