## Gotchas

- **The branch-policy hook can't unblock itself** — a commit that loosens its own rule for
  `develop` still runs the *old* rule until merged. Confirmed again this session; not a bug.
- **`claude plugin install`/`claude mcp add` can rewrite `.claude/settings.json` wholesale.**
  Always diff after running one — it can silently drop unrelated content (happened once already,
  see Done above). Re-verify the `permissions.deny` list specifically.
- **This machine's git needs `http.sslBackend=schannel`** for any `https://` clone (see Done). Not
  a global config change — apply per-command via `GIT_CONFIG_COUNT`/`GIT_CONFIG_KEY_0`/
  `GIT_CONFIG_VALUE_0` env vars, or ask the user before changing it globally.
- `claude plugin marketplace add owner/repo` tries SSH first and fails without keys configured —
  use the full `https://github.com/owner/repo` URL.
- Docker Desktop was not running this session either — `docker compose up -d` still not verified
  end to end. Do that as part of step 2 above.
- `mypy`, `import-linter`, `uv`, `pre-commit`, `gitleaks` still not installed on this machine.
- The domain layer must not import Pydantic — dataclasses only (import-linter + a textual test
