# docs

| Directory | What lives here |
|---|---|
| `architecture/` | how the system is shaped and why |
| `decisions/` | ADRs — decisions that constrain future work |
| `specs/` | Spec Driven Development: spec, plan, tasks per feature |
| `security/` | agent security rules and threat model |
| `playbooks/` | reusable procedures; these are what the skills of both agents execute |
| `runbooks/` | operational procedures (rollback, incident response) |
| `tooling/` | MCP / plugin / CLI research and adoption decisions |

`Agentic_GTM_Revenue_Operations_Platform_Guia_Projeto.pdf` is the product source of truth: scope,
roadmap, acceptance criteria and the AI Engineering concept matrix. Where it conflicts with an
accepted ADR on code structure, the ADR wins — the guide predates those decisions.
