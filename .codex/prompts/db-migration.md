# db-migration

Change a SQLAlchemy model and write a backward-compatible Alembic migration. Use for any schema change, index, or pgvector column.

Read `docs/playbooks/db-migration.md` and follow it. That playbook is shared with Claude Code
(`.claude/skills/db-migration/SKILL.md`) — edit the playbook, never the wrapper.

Project rules that always apply: `AGENTS.md`.
