# agent-tool

Add a new agent tool with its Pydantic schema, risk level, allowlist entry, port/adapter, validation chain, audit row, tests and eval case. Use when the agent needs a new capability that touches the CRM or the outside world.

Read `docs/playbooks/agent-tool.md` and follow it. That playbook is shared with Claude Code
(`.claude/skills/agent-tool/SKILL.md`) — edit the playbook, never the wrapper.

Project rules that always apply: `AGENTS.md`.
