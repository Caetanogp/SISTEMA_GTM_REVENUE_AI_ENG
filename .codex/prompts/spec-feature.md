# spec-feature

Drive a feature through Spec Driven Development: write spec.md, plan.md and tasks.md in docs/specs/ before implementing. Use when starting any non-trivial feature or change, or when the user asks for a new capability.

Read `docs/playbooks/spec-feature.md` and follow it. That playbook is shared with Claude Code
(`.claude/skills/spec-feature/SKILL.md`) — edit the playbook, never the wrapper.

Project rules that always apply: `AGENTS.md`.
